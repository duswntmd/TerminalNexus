# 고스톱 맞고(2인) 채택 규칙

화면 엔진 `engine.js`와 서버 엔진 `GostopGame.java`는 이 문서를 따른다. 시험은 `test/engine.test.mjs`(화면)와 `GostopGameTest.java`(서버).

고스톱은 지역·사이트마다 규칙이 다르다. 아래는 여러 자료를 교차 확인해 **온라인 맞고에서 흔히 쓰는 쪽**으로 정했고, 자료끼리 다른 항목은 무엇을 골랐는지 적었다.

## 출처 (2026-11-07 확인)

- [N1] 나무위키 「맞고」 https://namu.wiki/w/맞고
- [N2] 나무위키 「고스톱」 https://namu.wiki/w/고스톱 (본문과 각주)
- [G] 게임메카 맞고 공략 「제 1장: 맞고의 기본」 https://www.gamemeca.com/view.php?gid=124131 (2004년 글, 7점 기준 확인용)
- [W] Wikipedia 「Go-Stop」 https://en.wikipedia.org/wiki/Go-Stop (패 구성, 점수표)

위키는 누구나 고칠 수 있는 자료라 단일 출처로 정하지 않고, 서로 맞는 내용을 우선했다.

## 1. 패와 배분

| 항목 | 채택 | 근거 |
|---|---|---|
| 패 | 48장(월별 4장). 보너스피·조커 없음 | [W], [N1] 보너스피는 온라인 추가 규칙 |
| 배분 | 손패 10장씩, 바닥 8장, 뒷패(더미) 20장 | [N1] "손에 10장, 바닥에 8장, 더미에 20장" |
| 선 | 첫 판은 무작위, 이긴 사람이 다음 판 선. 나가리면 선 유지 | [N2] "승자는 자동적으로 다음 게임의 선", 나가리 시 선 유지 |
| 바닥에 같은 월 4장 | 나가리(다음 판 2배) | [N2] 바닥 총통 처리 중 피망 방식. 자료마다 다름 |
| 바닥에 같은 월 3장 | 한 더미로 두고, 4번째 패로 가져가는 사람이 피 1장을 받는다(자연뻑) | [N2] |
| 손에 같은 월 4장(총통) | 바로 승리, 10점 | [N2] 지역에 따라 3/5/10점. 맞고 7점 기준이라 10점을 채택 |

쌍피: 11월 오동 쌍피, 12월 비 쌍피 2장. 9월 국화 열끗(국진)은 열끗 또는 쌍피 중 선택([N2] §5, §7).

## 2. 차례 진행

1. 손패 1장을 낸다. 바닥에 같은 월이 1장이면 짝을 맞춘다. **같은 월이 2장이면 하나를 고른다**. 3장(뻑 더미)이면 모두 가져간다.
2. 뒷패 맨 위 1장을 뒤집어 같은 방식으로 맞춘다.
3. 먹은 패를 가져오고, 피 뺏기를 처리한 뒤 점수를 본다.

## 3. 특수 상황과 피 뺏기

피를 뺏을 때는 일반 피부터 주고, 일반 피가 없으면 쌍피를 준다([N2] §4.1 "쌍피만 있는 사람은 쌍피를 주어야 한다"). 상대에게 피가 없으면 받지 못한다.

| 상황 | 내용 | 피 | 근거 |
|---|---|---|---|
| 뻑 | 낸 패로 1장을 맞췄는데 뒤집은 패도 같은 월 → 3장이 바닥에 남음 | - | [N2] §4.1 |
| 뻑 먹기 | 남이 싼 뻑(또는 자연뻑)을 4번째 패로 가져감 | 1장 | [N2] §4.1 |
| 자뻑 | 자기가 싼 뻑을 가져감 | 2장 | [N2] §4.1 "맞고에서 많이 적용" |
| 쪽 | 낸 패가 짝 없이 깔렸는데 같은 월을 뒤집음 | 1장 | [N2] §4.3 |
| 따닥 | 바닥 같은 월 2장에 1장을 내고 4번째를 뒤집음 → 4장 모두 | 1장 | [N2] §4.2 |
| 싹쓸이(쓸) | 내 차례가 끝났을 때 바닥이 빔 | 1장 | [N2] §4.4 |
| 폭탄 | 손에 같은 월 3장 + 바닥에 1장 → 3장을 한꺼번에 내 4장을 먹음. 흔들기와 같이 ×2, 이후 손패 없이 뒤집기만 하는 차례(폭탄피) 2번 | 1장 | [N2] §4.5, §6 |
| 흔들기 | 손에 같은 월 3장, 바닥에 없을 때 보여 주고 냄. 이기면 ×2 | - | [N2] §6 |

- 위 효과가 한 차례에 겹치면 피도 더한다(예: 자뻑 + 쓸 = 3장) [N2] §4.4.
- **마지막 차례**(뒷패의 마지막 장을 뒤집는 차례)에는 뻑·쪽·따닥·쓸을 인정하지 않는다 [N2] §4.1~4.4. 패는 정상대로 먹지만 피를 뺏지 않고, 뻑은 세지 않는다.
- 첫뻑: 자기 첫 차례에 뻑 → 상대가 3점을 바로 준다. 연뻑: 첫 차례와 두 번째 차례에 연속으로 뻑 → 6점을 더 준다 [N2] 각주(지역에 따라 5/10점). 첫·연뻑 보너스는 판 결과와 상관없이 주고받는다(나가리여도).
- 3뻑: 한 판에 뻑을 3번(연속이 아니어도) 하면 바로 승리, 7점 [N1] 온라인은 통산 3뻑을 승리로 처리.

## 4. 점수 (7점부터 남)

| 족보 | 점수 | 근거 |
|---|---|---|
| 5광 | 15 | [N2] §5 |
| 4광 | 4 | [N2] §5 |
| 3광(비광 없음) | 3 | [N2] §5 |
| 비광 포함 3광 | 2 | [N2] §5 |
| 고도리(2·4·8월 새) | 5 | [N2] §5 |
| 홍단(1·2·3월 띠) / 청단(6·9·10월 띠) / 초단(4·5·7월 띠) | 각 3 | [N2] §5 |
| 띠 5장 | 1, 1장마다 +1 | [N2] §5 |
| 열끗 5장 | 1, 1장마다 +1 | [N2] §5 |
| 피 10장 | 1, 1장마다 +1 (쌍피는 2장) | [N2] §5 |

- 12월 비띠는 단에 들지 않는 띠다.
- 국진: 기본은 점수가 높은 쪽으로 자동 계산하고, 먹은 패 아래 버튼으로 열끗·쌍피를 고정할 수 있다. 진 쪽의 자동 국진은 박을 피하는 쪽으로 센다([N2] §7: 피박을 피하려고 열끗 칸으로 옮기는 경우).

## 5. 고/스톱

- 7점 이상이 되면 고 또는 스톱 [N1] "맞고는 7점이 되어야 난다", [G].
- 고를 한 뒤에는 그때보다 점수가 올라야 다시 묻는다. 남은 손패와 폭탄피가 없거나 뒷패가 떨어졌으면 바로 스톱한다.
- 역고(상대가 고한 뒤 내가 나는 경우 추가 배수)는 적용하지 않는다(자료마다 다름).

## 6. 정산

최종 점수 = (족보 점수 + 고 가산) × 배수들 [N2] §3 "더하는 점수를 먼저 더하고, 곱하는 배율을 나중에".

| 항목 | 내용 | 근거 |
|---|---|---|
| 고 가산 | 1고 +1, 2고 +2, 3고 +3 … | [N2] §6 |
| 고 배수 | 3고 ×2, 4고 ×4, 5고 ×8 … (3고부터 두 배씩) | [N2] §3, [N1] "8고 64배" |
| 흔들기·폭탄 | 1번마다 ×2 (이긴 사람이 한 경우) | [N2] §6 |
| 피박 | 이긴 사람이 피로 점수를 냈고(피 10장 이상) 진 사람 피가 7장 이하 → ×2 | [N1] "7장까지 피박", [N2] 각주 "맞고는 보통 7장" |
| 광박 | 이긴 사람이 광으로 점수를 냈고 진 사람 광이 0장 → ×2 | [N2] §6 |
| 멍따 | 이긴 사람이 열끗 7장 이상 → ×2 | [N2] §5·§6 "보통 맞고에서 멍따, 3인 고스톱에서 멍박" |
| 고박 | 고를 한 사람이 지면 진 사람이 ×2로 낸다 | [N2] §6 "맞고에서는 독박 대신 고박" |
| 나가리 | 아무도 나지 못하고 패가 끝남 → 다음 판 ×2, 연속이면 다시 ×2 (최대 ×16) | [N2] §4.8, 각주 |

멍박(진 사람 열끗 0장)은 3인 고스톱 규칙이라 맞고에서는 멍따를 적용한다([N2]).

## 7. 포인트

AI 대전은 점당 100P의 가상 포인트를 주고받는다. 현금 가치가 없고 충전·환전·결제·아이템 판매가 없다. 다 잃으면 10,000P로 다시 채운다. 온라인은 방 안에서 점수만 누적한다.
