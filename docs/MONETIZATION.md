# TerminalNexus 수익화 계획

추가 비용 없이 시작하는 것을 기준으로 정리했다. 금액 예상은 넣지 않았다. 실제 방문자 수와 광고 단가 자료가 아직 없어서 숫자를 쓰면 지어낸 값이 되기 때문이다.

## 수익 구조

방문자가 들어오는 길은 검색이다. 돈은 아래 순서로 붙인다.

```
검색 유입 (학습 글, 개발·인프라 도구)
  → 광고 (AdSense): 방문자가 적어도 바로 시작 가능
  → 자격증 연습 무료 체험
  → 이용권 결제
```

| 수익원 | 상태 | 시작 조건 |
|---|---|---|
| AdSense 광고 | 자리 구현됨, 슬롯 값 설정 전까지 안 보임 | 애드센스 승인, 광고 단위 생성 |
| 자격증 이용권 | 구현됨, 결제 꺼짐 | 사업자 등록, 약관, 문제 검수, 포트원 실결제 설정 |
| 후원 | 구현됨, 운영에서 포트원 키 없음 | 포트원 키 설정 후 소액 시험 |

## 사용자가 직접 해야 하는 일 (순서대로)

### 1. 배포 직후: 검색 등록
- Google Search Console: Sitemaps에 `https://tnhub.kr/sitemap.xml` 제출, 색인 생성 범위 확인
- 네이버 서치어드바이저: 사이트맵 제출, 주요 글 몇 개를 웹페이지 수집 요청
- 두 곳 모두 URL 검사에서 `/tools/json`과 `/learn/ssh-hardening`이 본문까지 보이는지 확인

### 2. AdSense
- 계정에서 사이트 승인 상태를 확인한다. `index.html`에 게시자 코드는 이미 있고 `ads.txt`도 공개되어 있다.
- 승인되면 디스플레이 광고 단위를 2개 만들어 슬롯 번호를 `frontend/.env`에 넣고 배포한다.

```
VITE_ADSENSE_SLOT_ARTICLE=글 하단 광고 슬롯 번호
VITE_ADSENSE_SLOT_TOOL=도구 페이지 광고 슬롯 번호
```

- 자동 광고를 켠다면 `/lotto`는 제외한다. 복권 관련 페이지가 도박 정책에 걸리는지 확인하지 못했기 때문이다.
- 로그인 화면, 빈 화면, 시험 응시 화면에는 광고를 넣지 않는다.
- 본인 광고를 직접 클릭하지 않는다. 계정 정지 사유다.

### 3. 자격증 이용권
- 켜기 전 절차는 `docs/HANDOFF.md` 참고. 무료 체험으로 사람이 실제로 쓰는지 본 뒤 진행해도 늦지 않다.

## 콘텐츠 운영

- 글은 `frontend/src/content/articles.js`에 추가하면 페이지, 목록, sitemap까지 자동으로 생성된다.
- 지금 글은 편당 약 1,500자다. 애드센스 심사에서 분량이 문제 되면 실제 장애 사례와 스크린샷을 넣어 늘린다.
- 직접 겪은 내용을 쓰는 것이 가장 강하다. 이 사이트는 라즈베리파이 자체 호스팅, Jenkins 배포, nginx 운영 경험이 있어서 다른 사이트가 쓰기 어려운 글이 나온다.
- 다음 글 후보: 라즈베리파이로 웹서비스 운영하기, Jenkins와 Docker 자동 배포, 502 오류 실제 해결 기록, MySQL 외부 노출 점검, 공유기 포트포워딩 보안.

## 측정

한 달에 한 번 Search Console에서 본다.

| 지표 | 해석 |
|---|---|
| 노출 많고 클릭 적은 글 | 제목과 설명을 고친다 |
| 평균 순위 8~20위 글 | 내용을 보강하면 효과가 크다 |
| 유입되는 검색어 | 다음 글 주제로 쓴다 |

## 비슷한 사이트에서 참고한 점

- 무료 도구 사이트는 AdSense에서 저가치 콘텐츠 판정을 자주 받는다고 알려져 있다. 그래서 도구마다 설명 글을 붙이고 별도 학습 글을 넣었다.
- 경쟁이 심한 일반 개발 도구만으로는 차별화가 어렵다. 한국어 설명, 리눅스 자격증, 라즈베리파이 운영 기록을 묶는 쪽이 이 사이트의 강점이다.
- 위 내용은 공개 글을 참고한 판단이며 구글의 공식 기준은 아니다.
